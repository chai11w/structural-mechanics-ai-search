# 题库 Agent 输出层升级：阶段 4 生产接入

## 结论

阶段 4 已把阶段 3 的确定性输出层接入 A2、A3 和 FastAPI 最终响应。
本阶段不调用模型润色；内部流程仍负责识别、检索、状态迁移和媒体选择，输出层只接收结构化事实并生成公开消息。

## 已完成

- 收紧 `RequestProtocol` V1 反序列化：公开反序列化要求精确字段、登记 code、匹配 status/layer/retryable/action；旧字典只能走显式兼容入口。
- A2 统一生成 `OutputDraftV1`，不再把原始错误、工具 detail 或自由 notice 直接交给用户。
- A3 在父流程组合题号、剩余题数、停止题证据和子 A2 结果；不再覆盖或拼接子回复文本。
- 图片先持久化，再确定最终公开状态：候选图片整批原子交付；答案图片按实际送达数区分完整、部分和零张失败。
- FastAPI 的结构化路径不读取 `AgentResponse.text`；协议或输出契约异常统一返回安全服务失败。
- A1/无外荷载、章节显示名、整页无可检索题、裁剪校验失败、会话失效等常见边界均有固定输出族。

## 明确不在本阶段

- 不新增模型润色调用。
- 不重写 progress、NDJSON 中间事件和公共 session snapshot；这些属于阶段 5。
- 阶段 4 当时暂留 `output=None` 兼容入口；阶段 6 已将其清理为固定安全失败。
