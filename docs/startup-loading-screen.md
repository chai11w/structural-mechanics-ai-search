# 力答启动加载页（6½ 阶段之前）

2026-09-21：本地实现及隔离验收完成，尚未发布到 8790。

## 行为

- 初始 HTML 自带白底加载页，并隐藏、禁用主界面交互，覆盖脚本下载前的首帧。复用企业 Agent 项目的视觉结构；标题为“力答”，两字用 16px 间距分开，64px 图标与标题间隔 22px。
- 500ms 后显示转圈和加载提示，8 秒后提供 HTML 重新加载链接；不设置最低展示时间。减少动态效果偏好下停止转圈。
- 普通启动由已有会话核对流程确认后展示正文；本地时钟不裁决过期，重置未获确认时保留历史。正在执行的后台任务由原任务权威查询解除遮挡，不等待旧运行时的长锁，不重发任务。
- 恢复失败保留加载页并提供重新连接、开始新对话和重新加载；登录失效提供重新登录。开始新对话沿用已有重置协议，只有确认成功才展示首页，协调失败仍保留历史。
- 恢复完成后不再重新遮住现有页面。任务执行期间的输入解锁、禁止发送及草稿保留维持原行为。
- 启动样式标记放在 html 元素，保留服务端对 body 标签注入后台协议标记的接口。CSS/JS 缓存版本为 `20260921-startup-v1`。
