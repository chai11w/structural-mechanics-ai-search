# 固定源码与各服务的外置配置

`TIKU_CONFIG_FILE` 指向部署者指定的、源码目录之外的绝对 JSON 文件。设置后，搜索、题目识别、主库/字母库构建和路由评估的现有配置读取器只读取此文件，不再叠加源码旁的 `config.json` 或 `config.local.json`。文件应包含该服务需要的完整业务设置；不能只搬一项密钥而遗漏原有设置。未设置该变量时保留原有配置加载顺序和错误处理。

外置文件必须是普通独立文件，最多 1 MiB；路径或祖先存在链接、硬链接、相对路径、源码内位置、缺失文件、重复 JSON 键、非有限数值或读取期间文件身份变化均拒绝。错误不带文件内容或路径，不会回退读取另一份旧配置。`TIKU_BANK_STORE` 仍决定实际发布题库版本；外置配置不能把受管读取改回旧生产目录。

此入口用于固定安装的服务配置，未新增模型工具或任意文件读取权限。部署时各服务只读自己的配置，凭据仍由服务端持有；真实账号、环境变量来源、NTFS 权限以及配置是否全部进入完整备份仍须安装验证。现有 `search.py store` 等直接写入口的受管拒绝继续有效。

## 飞书运行目录和费用来源

`scripts/tiku_bot_watchdog.ps1` 新增三个安装参数：

- `-RuntimeDir`：飞书日志、临时资料及现有会话协调器的运行目录，对应机器人 `--temp-dir`。
- `-PythonExe`：实际 Python 可执行文件，启动时解析固定路径并使用 `-B`。
- `-AdminFeeDatabase`：现有 8790 费用数据库的固定来源，对应机器人 `--admin-fee-db`，费用查询沿用原只读实现。

未启用受管题库时，未传参数仍使用原来的路径和解释器解析方式。启用 `TIKU_BANK_STORE` 时，要求明确的运行目录、绝对 Python 路径、现存费用库和 `TIKU_CONFIG_FILE`。运行目录必须与源码和发布题库互不包含；未指定 `TIKU_SEARCH_STATE_DIR` 时使用运行目录内的 `search-cache`，明确指定的缓存目录也必须位于该运行目录内。安装迁移仍需保留原资料，不能用创建空目录代替迁移。

启动参数复用已有 Windows 命令行编码，带空格的解释器、脚本和资料路径不会被拆成额外参数。`-FunctionsOnly` 只加载函数及配置检查，不创建运行文件或启动业务进程，供安装检查和测试使用；它不证明服务身份、配置内容、飞书认证或实际业务启动成功。
