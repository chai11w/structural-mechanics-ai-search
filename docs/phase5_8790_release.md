## 回退边界

新版本尚未接收业务写入时，可停掉新写入进程，恢复原 Action 和旧发布版本；
保留新执行库与备份用于核对。阶段五启动器检测到执行库而缺少启用开关时会拒绝启动，
防止误回到旧会话写入路径。

一旦已有新执行操作，禁止仅切回旧会话数据库。应保留新执行库、费用证据与媒体，
采用兼容阶段五状态的修复版本；涉及会话状态回退时须单独制定核对方案。
