## 分支核对与修复

| 场景 | 已有业务处理 | 本次执行层交付 |
| --- | --- | --- |
| 形状复筛部分或全部超时 | 返回初筛候选及未完成提示 | 保存原初筛排序，页面可继续选择 |
| 杆长复核失败 | 使用原有默认复核分值继续 | 保留候选，同时补齐线程中的执行与费用上下文 |
| 可选结构类型识别失败 | 跳过结构类型筛选 | 继续检索 |
| 旧多题探测失败 | 继续单题识别 | 保留原路由兜底 |
| A3 自动定位/裁图校验/外荷载校验失败 | 自动准备失败项转手动裁剪 | 保存选题状态，可进入手动裁剪 |
| 手动裁图校验/外荷载校验失败 | 保留裁剪草稿 | 保留草稿及提示，供用户继续操作 |
| 整页理解失败 | 保留原图并提示重试 | 保存错误回复，显式新操作可重试 |
| A2/A3 意图模型失败 | 请求澄清 | 交付澄清提示 |
| 安全回复或预检回复模型失败 | 使用固定回复 | 保留已确定的路由和固定提示 |
| 可选本地裁图写入失败且未发布 | 转手动裁剪 | 清理自身临时文件，记 ABORTED，交付兜底 |

修复不是把任意异常吞掉。实际题目识别等缺少可用结果的必要步骤，不伪造识别或检索结果。没有业务兜底的调用、仍在途的 SENT 调用、文件已发布而收据丢失、业务落盘前进程中断，继续保留未确认状态。
