# 控制请求失效后的会话恢复

2026-09-28：隔离修复已验证，生产发布状态待核验。

控制面板将持久操作编号与短期连接凭据绑定；凭据被会话读取核对或超过期限后，服务端返回 `STALE_ACTION`，浏览器仍反复发送原凭据。“开始新对话”也会重试同一控制请求。启动阶段遇到旧后台任务 `EXECUTION_NOT_FOUND` 时又提前退出，使用户无法核对当前会话。

显式重试现在只刷新连接凭据，保留原操作编号、epoch、状态版本及目标，由持久幂等协议判断执行或重放。控制提交与会话核对共用浏览器会话锁，避免提交过程中被另一读取提前核对。旧任务未找到时保留收据和聊天，继续读取当前会话；未知模型效果不重发，也不伪造成功。

变更只涉及网页控制和恢复流程及静态资源版本，CLI、旧飞书、模型和费用协议无变化。新增集成回归覆盖凭据先被核对、凭据过期、原操作重放和零模型调用；客户端回归覆盖丢失响应、刷新后重试、失效凭据、共享锁竞争和任务未找到时的启动恢复。共 98 项相关测试通过，JS 语法和差异检查通过。

发布须基于实际固定版本，保留生产独有诊断修复。切换前核验并备份运行状态和计划任务；UNKNOWN 任务及费用证据保留，不用旧数据库覆盖新记录。公网浏览器验收尚未完成前，不把 HTTP 探针视为完整验收。
