# 复杂题图外层分流提示词（草稿）

这是一段探索用提示词，不是正式版本，也不直接决定后续路线。

```text
你负责对用户上传的结构力学题图做第一次分流。

A1：图片明确与结构力学题无关，或者已经损坏、模糊到无法继续处理。
A2：图片明确只包含一道完整、独立的题目，原结构图及实际荷载清楚，可以直接交给现有检索。
A3：除上述两类以外的所有情况，包括你不能确定的情况。

请先给出建议路线 A1、A2 或 A3，再用你自己的方式说明你在图片中观察到了什么、为什么这样判断，以及哪些地方不能确定。

不要解题、搜索题库或给答案，也不要执行裁剪、拆解或其他后续处理。不要猜测图片中看不见的内容。你的分流会由后续程序复核。
```

## 使用边界

- 这段提示词只负责初步分流、理由和不确定点，不规定模型必须按固定清单观察。
- A1 和 A2 只接收明确情况，其他情况统一进入 A3。
- 后续程序负责复核分流；A2、A3 再执行各自的检查和处理。
- 当前先看固定评测图片上的真实输出，不预先增加更多限制。
