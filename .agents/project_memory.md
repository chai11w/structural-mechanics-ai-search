# Project Memory

## Current State

- 项目是结构力学题库检索器；CLI、飞书机器人和 Agent 共用核心检索逻辑，但运行状态彼此隔离。
- 8788 是飞书搜题工作流；8790 是邀请制网页主线；8793 是观察/评审镜像；8794 是隔离 Agent；8795 是独立管理员后台。
- 8790 当前仍使用原哈希邀请码配置和静态全站/单码额度，尚未切换到 8795 控制库；本轮没有停止或重启 8790。
- 8795 第一版已实现管理员登录、邀请码生命周期与动态额度、今日搜题/费用概览、单码用量、反馈筛选和完整对话详情；后台认证与用户邀请码会话完全隔离。
- 反馈案例保存用户当时可见的对话和相关题目/候选/答案图片，默认 30 天后清理；不保存邀请码明文、隐藏 Prompt、内部推理、密钥或本地路径。
- 8790 可通过 `--control-db` 在每次请求前动态读取邀请码状态与全站/单码额度；停用或重置会递增认证版本并使旧 Cookie 失效。
- 8790 保持 1 个活动任务、2 个排队任务、最长等待 55 秒；费用按 Asia/Shanghai 自然日，金额是项目估算，不等同供应商账单实扣。
- 当前题库共 280 行，只有 24 行满足 >20，均属“4力法—钢架—均布 q”组；真实覆盖仍窄。
- 完整 440 项测试通过；8795 已完成 1440×1000 与 390×844 浏览器验收，邀请码全流程、反馈日期/原因筛选、单题费用、完整对话、设置保存均通过，浏览器错误和警告为 0。

## Implemented

- `dimensions.py`、`structure_dimensions.py`：尺寸解析、归一化、结构约束、缓存和 Qwen `qwen3.7-plus` 识别。
- `multi_agent_pipeline.py`、`search.py`、`tiku_agent/tools.py`、`tiku_agent/agent.py`：共享荷载检索、尺寸复筛和视觉重排。
- 全尺寸和单边尺寸不区分横竖方向；缺边不按图形比例补齐。拱不参与复筛。
- 字母库全局搜索仅在章节判断失败且用户明确授权后执行；跨第 2–8 章按结构类型收集并去重。
- 支持章节问题走零模型、零业务工具的代码事实回答；混有搜题指令时仍走 Intent V2。
- 8790 具备有界执行、同会话串行、过期会话清理、媒体 no-store、安全响应头及忙碌/额度中文错误。
- `tiku_shared/model_costs.py`：费用台账按稳定邀请码身份记录搜题次数和估算费用，兼容迁移旧 SQLite schema。
- `tiku_agent/feedback_store.py`：支持反馈去重更新/取消、可见对话与媒体案例、章节与检索键、处理状态/备注及到期清理。
- `tiku_admin/control_store.py`：只保存管理员密码哈希和邀请码哈希，支持邀请码新增、编辑、停用、恢复、重置、归档、独立额度、到期时间、全局设置与审计日志。
- `tiku_admin/app.py`、`auth.py`、`reporting.py` 和 `web/`：提供独立 8795 FastAPI 后台；邀请码明文仅创建或重置时显示一次。
- 8795 概览显示今日搜题、估算总费用、启用邀请码、待处理点踩和每码费用；反馈可按日期、评价、原因、邀请码、章节、处理状态筛选并跳转完整对话。
- `scripts/run_tiku_admin.py`、`manage_tiku_admin.py`、`tiku_admin_watchdog_8795.ps1`：提供启动、旧哈希配置导入和独立保活入口。
- `scripts/run_tiku_agent_demo.py` 与 8790 看门狗支持可选 `--control-db` / `-ControlDb`；控制库模式拒绝同时使用旧邀请码配置或静态额度参数。

## Architecture Rules

- 8795 独立运行在 8790 之外，管理员认证、Cookie、运行目录和控制数据不得与用户邀请码会话混用。
- 费用按稳定邀请码身份归属，不按可刷新或清除的临时会话 Cookie 归属。
- 保留单邀请码额度与全站保险上限；调整邀请码数量或单码额度时同步核算理论总暴露。
- 邀请码只保存哈希；明文仅在创建或重置时显示一次，后台不得长期存储、找回或再次展示。
- 迁移 8790 前先导入原哈希邀请码配置；`--control-db` 与 `--invite-config`、静态费用上限不得混用。
- 预算在任务准入前检查、完成后落账；当前全局单任务并发用于防止并发穿透额度。
- 费用是依据版本化目录价格和 usage 的估算；缺失 usage 或价格时不能宣称等同供应商账单。
- 反馈只保留最小必要可见上下文；案例到期后清理对话和媒体，评分、原因与处理状态继续保留。
- 修改检索、储存或索引逻辑时同步检查 CLI、飞书、Agent 和项目 Skill 文档。
- 题库写操作继续 plan → confirm → backup → execute；8790、8793、8794、8795 与 8788 的状态和端口保持隔离。

## Known Risks

- 在 8790 完成控制库迁移前，管理员可能误以为后台修改已作用于线上；页面和 README 已明确提示该边界。
- 邀请码被转发会共享同一 3 元额度；签名 Cookie 防伪造但不能阻止持码人主动共享。
- 费用完成后入账，因此最后一个在途任务可能使单码或全站金额略高于阈值。
- usage 缺失、价格目录缺项或供应商规则变化会造成估算偏差；30 元不是支付平台硬限额。
- 8795 目前只有应用层管理员门禁；绑定公网子域名前必须增加 Cloudflare Access/WAF 外层保护。
- Qwen 冷调用有长尾；候选下降不保证首次总耗时一定下降。
- 2026-07-29 曾有旧 API 密钥出现在进程命令行和工具输出；旧进程已终止，用户当时选择暂不轮换。

## Do Not Do

- 不读取、提交或展示 API key、Tunnel token、邀请码明文、管理员密码、私有发放清单和本地敏感配置。
- 不把管理员认证并入用户邀请码会话，不把 8795 部署进 8790 进程。
- 不在导入原邀请码并确认维护窗口前切换或重启当前 8790。
- 不把邀请码身份改回会话 Cookie，也不删除全站保险上限只保留单码额度。
- 不跨章节搜索，不绕过项目脚本的识别、过滤和排序。
- 不在未授权时把图片发给外部模型，不重复已完成的题库原图付费评测。
- 不随意停止或改造 8788；部署重启必须精确限定目标端口与进程。
