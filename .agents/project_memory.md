# Project Memory

## 当前状态

- 项目是结构力学题库检索器；CLI、飞书机器人和新 Agent 共用核心检索逻辑，但运行状态必须彼此隔离。
- 8788 是现有飞书题库机器人；8790 是稳定网页主线；8793 是独立评审镜像；8794 是隔离候选服务，有限自主化仍暂缓，详见 `.agents/roadmap.md`。
- 当前产品优先级已从继续叠加模型能力转为把现有检索推向真实用户；推荐入口是邀请制网页内测，不要求用户使用飞书，也暂不训练自有模型。
- 尺寸复筛已在 8788、8790、8793、8794 和多 Agent CLI 默认开启；所有入口均保留 `--disable-dimension-filter` 显式回退，不改变原有尺寸识别提示词、匹配规则或阈值。
- 触发条件：题目为符号尺寸、已知参与结构类型、荷载满分候选严格大于 20；沿用前序结构类型，不重复识别。
- 复筛只调用一次 Qwen V5.2。完整尺寸精确不符会删除；单边命中只前排；单边缺失或不符仍保留；异常、冲突、结果未验证或将删空时回退原候选。
- 拱不参与；梁的完整尺寸必须含 0；钢架、桁架和组合结构的完整尺寸不得含 0。尺寸缓存键含图片、模型、提示词版本和结构类型。
- 当前库共 280 行，只有 24 行满足 `>20`，且全部属于“4力法—钢架—均布 q”一组；钢架单边组最多 20，梁最多 8，桁架最多 13。
- 主仓 418 项测试、8793 镜像 23 项一致性测试和 287 项 Agent 测试均通过，相关 CLI 帮助和前端语法检查通过。

## 风险与约束

- Qwen 冷调用有长尾，`15×10` 样本曾用 6.326 秒；候选虽由 24→1，首次总时长仍可能不降反升。
- 题库包含历史人工补全错误，缺边时只能保留单边，禁止凭视觉比例补另一边。
- 智谱候选同分时顺序可能不稳定；判断效果应先看原题是否保留、正确答案是否进入前列，再看顺序。
- 不读取或提交密钥、题库资产、模型日志和临时缓存；任何题库写操作继续执行 plan → confirm → backup → execute。
- 2026-07-29 曾有旧 API 密钥出现在本机进程命令行和工具输出；相关进程已终止且启动方式已修正，用户当时选择暂不轮换，残余风险仍存在。
- 不跨章节搜索，不绕过项目脚本的识别和排序逻辑，不在未授权时把图片发送给外部模型。
