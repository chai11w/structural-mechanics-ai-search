## Implemented

- 主库与字母库共用显式文字类型快路径和千问图片分类；组合结构优先归钢架。章节、全局、继续搜索及 CLI 图片入口传递结构类型；主库跳过尺寸，字母库保留原尺寸逻辑，纯荷载无图检索不增加结构模型调用。

## Known Risks

- 结构误判但仍存在同类候选时可能排除正确题；未知/无匹配类型回退不保证消除漏召回。新增题目也需要独立存题入口保持元数据一致。
- 历史全量 1827 项有题库保留策略 7 个失败断言、2 个错误，原分支亦复现；本轮未重跑全量。`test_bank_retention_execution` 仍需核对旧冻结计划与保留发布版本策略，不能直接删除断言。
- Trace marker 与诊断入库之间崩溃可能丢事件，历史写失败未补回，重启归零不代表修复；诊断不替代业务权威。
- 未知费用每笔 1 元预留是运营估计，非供应商收费上界；9 月 29 日授权清空也不是历史对账成功。普通在途请求可能略超日额度，供应商恰好一次不在保证范围内。
- 公网及单次真实搜索验收不覆盖所有浏览器、弱网、全局检索或模型样本；父子错绑、跨题费用、混排、裁剪边界、小荷载、低清及旋转仍需具体样本验证。
- 业务 SUCCEEDED 与 publication READY/FAILED/UNAVAILABLE 分开；交付最多尝试 3 次，容量或到期失败保留收据。Qwen 冷调用有长尾；无人登录冷启动未通过本轮验收。
- 旧 parse_chapter 将“第4章”映射为 `4力法`，严格入口对纯数字返回 uncertain；未接入受管版本的旧题库引用仍可能受文件移动影响。
