- 尺寸复筛在所有入口默认开启：荷载满分候选严格大于 20 时，按结构类型和显式尺寸过滤后再视觉重排；异常或删空时回退。

## Implemented

- `dimensions.py`、`structure_dimensions.py`：尺寸解析、归一化、结构约束、缓存和 Qwen `qwen3.7-plus` 识别。
- `multi_agent_pipeline.py`、`search.py`、`tiku_agent/tools.py`、`tiku_agent/agent.py`：共享荷载检索、尺寸复筛和视觉重排。
- 全尺寸和单边尺寸不区分横竖方向；缺边不按图形比例补齐。拱不参与复筛。
- 字母库全局搜索仅在章节判断失败且用户明确授权后执行；跨第 2–8 章按结构类型收集并去重。
- 支持章节问题走零模型、零业务工具的代码事实回答；混有搜题指令时仍走 Intent V2。
- 8790 具备有界执行、同会话串行、过期会话清理、媒体 no-store、安全响应头及忙碌/额度中文错误。
- `tiku_agent/invite_access.py`：邀请码哈希验证、签名到期 Cookie、停用校验和随机邀请码生成。
- `tiku_agent/fastapi_demo.py`：未登录拦截、邀请码登录/退出、4 KB 登录请求上限，并传递稳定邀请码身份。
- `tiku_shared/model_costs.py`：费用台账 schema v2 增加 `identity_key`，兼容迁移旧 SQLite，支持按邀请码汇总。
- `tiku_agent/session_runtime.py`：全站与单邀请码双层每日费用熔断；缺少有效身份不能绕过单码额度。
- `scripts/manage_tiku_invites.py`：生成哈希配置和本地私有发放清单，拒绝覆盖已有文件。
- 8790 看门狗与计划任务已用全站 30 元、单邀请码 3 元和本地邀请码配置启动。
- 每条正常助手回复下方只有点赞、点踩和时间；点击后可选搜题场景常用原因并填写 300 字以内的补充说明。

## Architecture Rules

- 费用按稳定邀请码身份归属，不按可刷新或清除的临时会话 Cookie 归属。
- 保留单邀请码额度与全站保险上限；调整邀请码数量或单码额度时同步核算理论总暴露。
- 邀请码只保存哈希；明文清单、本地配置、模型日志和运行状态不得进入 Git。
- 预算在任务准入前检查、完成后落账；当前全局单任务并发用于防止并发穿透额度。
- 费用是依据版本化目录价格和 usage 的估算；缺失 usage 或价格时不能宣称等同供应商账单。
- 反馈只记录最小必要上下文；网页提交大小限制 4 KB，详情限制 300 字，标签由服务端白名单校验。
- 修改检索、储存或索引逻辑时同步检查 CLI、飞书、Agent 和项目 Skill 文档。
- 题库写操作继续 plan → confirm → backup → execute；8790、8793、8794 与 8788 的状态和端口保持隔离。

## Known Risks

- 邀请码被转发会共享同一 3 元额度；签名 Cookie 防伪造但不能阻止持码人主动共享。
- 费用完成后入账，因此最后一个在途任务可能使单码或全站金额略高于阈值。
- usage 缺失、价格目录缺项或供应商规则变化会造成估算偏差；30 元不是支付平台硬限额。
- 当前网页只有应用层邀请码门禁；Cloudflare Access/WAF 登录限速仍可加强外层防护。
- Qwen 冷调用有长尾；候选下降不保证首次总耗时一定下降。
- 2026-07-29 曾有旧 API 密钥出现在进程命令行和工具输出；旧进程已终止，用户当时选择暂不轮换。

## Do Not Do

- 不读取、提交或展示 API key、Tunnel token、邀请码明文、私有发放清单和本地敏感配置。
- 不把邀请码身份改回会话 Cookie，也不删除全站保险上限只保留单码额度。
- 不跨章节搜索，不绕过项目脚本的识别、过滤和排序。
- 不在未授权时把图片发给外部模型，不重复已完成的题库原图付费评测。
- 不随意停止或改造 8788；部署重启必须精确限定目标端口与进程。
