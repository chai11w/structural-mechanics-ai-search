## Architecture Rules

- 8795 独立运行在 8790 之外，管理员认证、Cookie、运行目录和控制数据不得与用户邀请码会话混用。
- 费用按稳定邀请码身份归属，不按可刷新或清除的临时会话 Cookie 归属。
- 保留单邀请码额度与全站保险上限；调整邀请码数量或单码额度时同步核算理论总暴露。
- 8790 认证始终只读取邀请码哈希；8795 可单独加密保存新建/重置邀请码的可恢复副本，列表只显示脱敏值，完整值仅经管理员会话、CSRF 和审计保护的复制接口返回。
- 旧邀请码只有哈希，必须重置后才可复制；`control.sqlite3` 与加密密钥必须一起保护和迁移。
- 迁移 8790 前只读核对旧配置与控制库的 ID、哈希、状态和认证版本；冲突禁止写入，不能把幂等导入当作线上兼容证明。
- 预算在任务准入前检查、完成后落账；当前全局单任务并发用于防止并发穿透额度。
- 费用按目录价格和 usage 估算，缺数据时不能视为供应商实扣。
- 反馈只保留最小必要可见上下文；案例到期后清理对话和媒体，评分、原因、编号、归档与处理状态保留。搜题耗时定义为上传题图至首批候选页面可见的等待时间。
- 修改检索、储存或索引逻辑时同步检查 CLI、飞书、Agent 和项目 Skill 文档。
- live 题库根为 `D:\桌面\答疑、帮做\结构力学\帮做`，字母库为旁边的 `帮做_字母库`；仓库根同名章节 Excel 是历史跟踪副本、行数与 live 不一致，写操作必须针对 live 根。`config.local.json` 当前无 `root`，`search.py` 回退该默认根。
- 题库写操作继续 plan → confirm → backup → execute；8790、8793、8794、8795 与 8788 的状态和端口保持隔离。

## Known Risks

- 旧 `parse_chapter` 仍会把“第4章”映射为内部 `4力法`，但严格 `parse_chapter_scope` 已对版本未知纯数字返回 `uncertain`；入口尚未迁移前，直接复用旧接口仍可能误搜。现有模型 `unknown` 还混合了动力学、稳定、极限荷载等明确超范围题。
- 新理解层尚未证明可替代并行外荷载 A 层；A 应先保留并影子对照非题目、无外荷载、普通题和复杂多图题，达标后再退役。
- A3 已使用 `unit_id` 和双向图引用，但真实回归仍只有 4 张整页、1 道完整裁剪链路；密集页面模型调用较慢，裁剪边界过紧时校验器可能要求用户扩大范围。
- 影子预检在固定线路后台运行；模型失败、解析失败和队列满都只记录，不影响用户返回。
- A/B 取消不能撤回已发出的模型请求，仍需观察误拦截、15 秒长尾和额外费用。
- 邀请码被转发会共享同一 3 元额度；签名 Cookie 防伪造但不能阻止持码人主动共享。
- 费用完成后入账，因此最后一个在途任务可能使单码或全站金额略高于阈值。
- usage 缺失、价格目录缺项或供应商规则变化会造成估算偏差；30 元不是支付平台硬限额。
- `admin-tiku.cysbuting.cn` 已接入 Tunnel，但 Access/WAF 未启用，公网目前只有应用层管理员门禁且缺少登录失败限速。
- Qwen 冷调用有长尾；候选下降不保证首次总耗时一定下降。
- 2026-07-29 曾有旧 API 密钥出现在进程命令行；旧进程已终止，用户暂不轮换。

## Do Not Do

- 不读取、提交或在工具输出、日志、项目文档中展示 API key、Tunnel token、邀请码明文、管理员密码、私有发放清单和本地敏感配置；管理员页面的受控复制功能除外。
- 不把管理员认证并入用户邀请码会话，不把 8795 部署进 8790 进程。
- 不因后台记录的 ID/哈希一致就假定旧邀请码可用；灾备切换还必须核对状态并验证登录和动态撤销。
- 不把邀请码身份改回会话 Cookie，也不删除全站保险上限只保留单码额度。
- 不跨章节搜索，不绕过项目脚本的识别、过滤和排序。
- 不在未授权时把图片发给外部模型，不重复已完成的题库原图付费评测。
- 不随意停止或改造 8788；部署重启必须精确限定目标端口与进程。
