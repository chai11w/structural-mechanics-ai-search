## Architecture Rules

- 8795 独立于 8790；管理员认证、Cookie、运行目录和控制数据不得与用户会话混用。
- 费用归属稳定邀请码，不按临时 Cookie；保留单码额度和全站上限，调整时核算理论总暴露。
- 8790 只读邀请码哈希；8795 可加密保存新建/重置码，完整值仅由受会话、CSRF 和审计保护的接口返回。旧码须重置后才可复制，控制库与密钥必须一起迁移。
- 迁移 8790 前只读核对旧配置与控制库的 ID、哈希、状态和认证版本；冲突禁止写入。
- 预算在任务准入前检查、完成后落账；当前全局单任务并发用于防止并发穿透额度。
- 费用按目录价格和 usage 估算，不等同供应商实扣。
- 反馈只留必要上下文并到期清理；搜题耗时从上传至首批候选可见。
- 修改检索、储存或索引逻辑时同步检查 CLI、飞书、Agent 和项目 Skill 文档。
- live 题库根为 `D:\桌面\答疑、帮做\结构力学\帮做`，字母库为相邻 `帮做_字母库`；仓库 Excel 是历史副本，写操作必须针对 live 根。
- 题库写操作继续 plan → confirm → backup → execute；8790、8793、8794、8795 与 8788 的状态和端口保持隔离。

## Known Risks

- 旧 `parse_chapter` 仍会把“第4章”映射为内部 `4力法`；8896 已改用严格目录并对纯数字返回 `uncertain`，其他未迁移入口直接复用旧接口仍可能误搜。
- 新理解层尚未证明可替代并行外荷载 A 层；A 应先保留并影子对照非题目、无外荷载、普通题和复杂多图题，达标后再退役。
- A3 已使用 `unit_id` 和双向图引用并安全处理未引用空组，但真实样本仍少；密集页较慢，裁剪过紧时仍可能要求扩大范围。
- 影子预检在固定线路后台运行；模型失败、解析失败和队列满都只记录，不影响用户返回。
- A/B 取消不能撤回已发出的模型请求，仍需观察误拦截、15 秒长尾和额外费用。
- 邀请码被转发会共享同一 3 元额度；签名 Cookie 防伪造但不能阻止持码人主动共享。
- 费用完成后入账，最后一个在途任务可能略超阈值；usage/价格缺失也会造成估算偏差，30 元不是支付平台硬限额。
- `admin-tiku.cysbuting.cn` 已接入 Tunnel，但 Access/WAF 未启用，公网目前只有应用层管理员门禁且缺少登录失败限速。
- Qwen 冷调用有长尾；V1+Qwen 首轮平均约 1.93 秒，仍需观察 8896 长尾和限流；8788/8790 暂不切换。
- 2026-07-29 曾有旧 API 密钥出现在进程命令行；旧进程已终止，用户暂不轮换。
