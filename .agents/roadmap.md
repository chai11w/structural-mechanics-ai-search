# 8794 Bounded Autonomy Roadmap

## Goal

把8790固定编排升级为“固定编排主干 + 编排之外的权限内有限自主”。8794是下一版纯主线候选；8793切换到8794 commit验收后，8794代码再替换8790。

## Non-goals

- 不重写检索、粗筛或视觉复筛算法。
- 不把所有请求改成AI规划，不开放自由多工具循环。
- 不把8793技术评审侧栏放进8794。
- 不改造8788，不自主化题库写操作。
- 不在本阶段接入LangGraph。

## Delivery Stages

### 1. Isolated 8794 Baseline — Completed

- 已创建 `codex/mainline-bounded-autonomy-v1`。
- 已使用独立8794端口、runtime、session、媒体、incoming、日志、Cookie和启动入口。
- 已以同输入、同mock依赖比较8790与8794的响应、状态、调用序列和API行为；Agent行为未改变。

### 2. Structured Tool Outcomes

- 工具统一返回 `SUCCESS / NO_MATCH / NEEDS_INPUT / PARTIAL / TOOL_ERROR`。
- 同时返回候选数、是否完成、可重试性和安全错误类别。
- 编排代码据此确定未命中、失败和下一步，不让AI猜。

### 3. Shadow Planning and Permission Contract

- Planner只输出结构化目标、步骤、参数和停止条件。
- 权限层按phase、题目版本、候选批次、章节授权、参数范围和副作用审核。
- 先只记录计划与审核结果，不执行工具、不改变用户响应；用8793观察越权、循环和无效计划。

### 4. Bounded Executor

- 只执行审核通过的只读计划。
- 每回合最多规划一次，计划外结果最多重规划一次；工具总数有硬上限，同一失败工具最多重试一次。
- 达到预算后停止并安全追问；旧版本操作和写操作一律拒绝。

### 5. Selective Autonomy

- 明确上传、章节、当前候选、继续搜索和答案回看继续走固定快速路径。
- 只在多轮指代、目标切换、部分完成或多个合法兜底路径中触发Planner。
- 记录模型调用数、工具数、单回合/完整任务耗时、纠正次数和错误执行数。

### 6. 8793 Acceptance and Promotion

- 将8793镜像manifest切换到8794确定commit，保留独立数据与完整评审层。
- 复跑主线回归、镜像一致性、跨重启、旧操作、越权、循环限制及真实长尾样本。
- 验收通过后合并并把8794代码部署到8790；8793继续基于新主线观测。

## Acceptance Gates

- 8790、8793、8788在开发期间持续可用，运行数据无交叉。
- 普通快速路径不调用Planner，现有明确指令和按钮行为不回退。
- 工具未命中与错误由代码按协议区分，不依赖AI自报。
- 禁止动作、越界参数、旧题/旧候选执行数为0；写工具调用数为0。
- Planner每回合不超过1次，重规划不超过1次；达到预算必定终止。
- 复杂样本同时报告直接完成、安全追问、可恢复、错误执行、额外回合与完整任务耗时。
- 8793必须证明镜像来源commit、行为一致性和独立runtime；评审失败不得影响主线结果。
- 发布前保留8790可回退版本和运行数据备份。

## LangGraph Gate

8794行为稳定后，只有确实需要跨请求暂停/恢复、人工确认、持久checkpoint或现有分支难维护时，才在后续独立阶段评估LangGraph。迁移先做行为等价对照，不同时增加新自主能力。
