# 8794 Bounded Autonomy Roadmap

## Goal

把8790固定编排升级为“固定编排主干 + 编排之外的权限内有限自主”。安全回答 V0、五态工具结果和视觉方向校准已提升到8790；8794先补齐安全回答与当前状态的连接，再进入影子规划，8793持续镜像当前8790并保留完整评审层。

## Non-goals

- 不重写检索、粗筛或视觉复筛算法。
- 不把所有请求改成AI规划，不开放自由多工具循环。
- 不把8793技术评审侧栏放进8794。
- 不改造8788，不自主化题库写操作。
- 不在本阶段接入LangGraph。
- 状态感知安全回答只连接当前持久业务状态，不在同一阶段引入完整短期记忆。

## Delivery Stages

### 1. Isolated 8794 Baseline — Completed

- 已创建 `codex/mainline-bounded-autonomy-v1`。
- 已使用独立8794端口、runtime、session、媒体、incoming、日志、Cookie和启动入口。
- 已以同输入、同mock依赖比较8790与8794的响应、状态、调用序列和API行为；Agent行为未改变。

### 2. Safe Conversational Replies — Completed

- 身份、能力、工作方式、寒暄、致谢和告别等无需业务操作的问题，允许模型在角色与安全边界内自由组织简短回答。
- 采用负面边界：业务操作、结果/状态依赖、敏感信息和越界请求不进入安全回答；安全信号与业务信号混合时业务优先。
- 此路径不调用工具、不修改题目/章节/候选状态、不编造题库结果；模型失败或输出校验不通过时使用安全兜底。
- 已用“你是谁”、能力询问、自然寒暄与告别等真实样本验收，并保留原业务编排回归测试。
- 已提升到8790生产主线；8794不关闭，继续承载后续自主做事开发。

### 3. Structured Tool Outcomes — Completed

- 工具统一返回 `SUCCESS / NO_MATCH / NEEDS_INPUT / PARTIAL / TOOL_ERROR`。
- 同时返回工具名、稳定原因码、业务数据、下一状态、是否完成、可重试性和安全错误类别。
- 固定编排已经按五态确定未命中、补充输入、可用降级和真实失败，不再依赖单一 `true/false` 猜原因。
- 九个业务工具及候选动作解析器均由统一边界绑定工具名，保留旧 `ok` 构造器作为临时测试兼容层。
- 已通过主线263项全量测试和真实题图复验并提升到8790；安全回答和现有业务编排未改为自主执行。

### 4. State-Aware Safe Replies — Candidate Review

- 保留现有负面业务边界：无需工具的寒暄、致谢和能力问答才进入安全回答，选择候选、继续搜索、查答案等操作仍走固定状态机。
- 代码从`AgentState`生成白名单摘要，只允许phase、章节、候选数量、允许动作、上一步和等待事项；不提供路径、完整候选、模型原文、内部错误或其他用户状态。
- 模型在严格六字段白名单内自然表达；题图与答案存在性只供代码校验，不交给模型。代码校验无虚构执行、无编造结果、无敏感信息且状态不变；模型失败时使用通用安全兜底，完整阶段提示继续由既有业务状态机负责。
- 验收候选阶段寒暄、等待章节致谢、答案后寒暄、业务操作不误入、跨重启恢复和跨用户隔离；先在8794实现，经8793评审后再提升8790。
- 唯一候选下的“是/对/可以”等简短确认由固定Intent规则直接选择候选1；不为这个高确定性场景引入自主Planner，多候选和复合表达继续澄清。

### 5. Shadow Planning and Permission Contract

- Planner只输出结构化目标、步骤、参数和停止条件。
- 权限层按phase、题目版本、候选批次、章节授权、参数范围和副作用审核。
- 先只记录计划与审核结果，不执行工具、不改变用户响应；用8793观察越权、循环和无效计划。

### 6. Bounded Executor

- 只执行审核通过的只读计划。
- 每回合最多规划一次，计划外结果最多重规划一次；工具总数有硬上限，同一失败工具最多重试一次。
- 达到预算后停止并安全追问；旧版本操作和写操作一律拒绝。

### 7. Selective Autonomy

- 明确上传、章节、当前候选、继续搜索和答案回看继续走固定快速路径。
- 只在多轮指代、目标切换、部分完成或多个合法兜底路径中触发Planner。
- 记录模型调用数、工具数、单回合/完整任务耗时、纠正次数和错误执行数。

### 8. 8793 Acceptance and Promotion Checkpoints

- 每个可独立验收的自主阶段先在8794验证，再提升到8790；安全回答 V0、五态工具结果和视觉方向校准均已完成提升。
- 8793镜像manifest持续指向当前8790的确定commit，保留独立数据与完整评审层。
- 复跑主线回归、镜像一致性、跨重启、旧操作、越权、循环限制及真实长尾样本。
- 后续结构化工具结果、影子规划和有限执行仍分别验收、分别提升；8793继续基于每次新主线观测。

## Acceptance Gates

- 8790、8793、8788在开发期间持续可用，运行数据无交叉。
- 普通快速路径不调用Planner，现有明确指令和按钮行为不回退。
- 工具未命中与错误由代码按协议区分，不依赖AI自报。
- 禁止动作、越界参数、旧题/旧候选执行数为0；写工具调用数为0。
- Planner每回合不超过1次，重规划不超过1次；达到预算必定终止。
- 复杂样本同时报告直接完成、安全追问、可恢复、错误执行、额外回合与完整任务耗时。
- 8793必须证明镜像来源commit、行为一致性和独立runtime；评审失败不得影响主线结果。
- 发布前保留8790可回退版本和运行数据备份。

## LangGraph Gate

8794行为稳定后，只有确实需要跨请求暂停/恢复、人工确认、持久checkpoint或现有分支难维护时，才在后续独立阶段评估LangGraph。迁移先做行为等价对照，不同时增加新自主能力。
